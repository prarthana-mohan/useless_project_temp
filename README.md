### Project Description

MindReader.exe is a real-time AI comedy application that uses a laptop webcam and computer vision to observe visible facial behavior such as eye openness, eyebrow movement, mouth movement, smiles, head movement, and facial landmarks.

It then turns these signals into completely fictional and absurd "mind-reading" commentary, accompanied by dynamically selected comedy sounds. It cannot actually read thoughts — it confidently makes them up.

### The Problem (that doesn't exist)

Have you ever wondered what your computer thinks you're thinking?

Unfortunately, computers have no idea.

This creates a completely unnecessary problem: **people have faces, computers have cameras, and nobody is making completely ridiculous assumptions about what those faces are supposedly thinking.**

MindReader.exe exists to solve this extremely important problem that nobody asked us to solve.

### The Solution (that nobody asked for)

MindReader.exe uses real-time facial landmark detection and temporal facial-signal analysis to detect visible reactions such as smiling-looking, surprised-looking, confused-looking, serious-looking, looking away, and other observable changes.

A comedy engine then converts those signals into fictional inner-monologue-style commentary such as:

> "Why did I open this tab?"

> "My last brain cell just resigned."

> "THE BRAIN HAS LEFT THE CHAT."

The system combines computer vision, temporal analysis, event detection, procedural audio, animations, and session analytics to create a technically serious solution for a completely useless purpose.

# Installation

Clone/download the project and open the project folder in VS Code.

Install dependencies:

```bash
npm install
```

The application is designed to work without an external AI API key because the primary comedy engine is rule-based and runs locally.

Optional AI commentary functionality can be configured using environment variables if enabled.

Create a `.env` file from `.env.example` when required.

# Run

Start the Vite development server:

```bash
npm run dev
```

Open the local URL displayed in the terminal, normally:

```text
http://localhost:5173
```

Allow webcam access when prompted.

For a production build:

```bash
npm run build
```

To preview the production build:

```bash
npm run preview
```
